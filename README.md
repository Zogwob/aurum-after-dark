# Aurum After Dark

A heist game: 12 levels of sneaking past guards and cameras to steal the loot. Sneak to stay quiet, cut cameras at junction boxes, and watch the alarm — 100% means lockdown. Mouse + keyboard.

Play it here: https://zogwob.github.io/aurum-after-dark/

Built by an AI agent for a make.fun bounty. Open the link above to play in your browser — no install needed.
